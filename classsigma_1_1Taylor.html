Detailed Description

template<typename ValueType>
class sigma::Taylor< ValueType >

Implements truncated multivariate polynomial algebra.

Template Parameters
ValueTypeThe numeric type of the constant term and coefficients.

Follows the design described in docs/taylor.md, which this class implements Eq. \(\eqref{eq:tm-poly}\) of:

\[ P(\delta) = \sum_{\left|\beta\right| \leq n} c_{\beta}\, \delta^{\beta} \qquad \delta \in [-1, 1]^v \]

where each expansion variable \(\delta_i\) is normalized to \([-1, 1]\), exactly as Affine's error symbols are.

Taylor is a truncated polynomial and nothing else: it makes no claim to enclose any particular function, and arithmetic that would produce terms above the truncation order simply discards them (there is no remainder to put them in). TaylorModel, which will pair a Taylor with a remainder interval_t to restore that guarantee, is not yet implemented; nor are the elementary functions (exp, log, sqrt, ...), the Eigen compatibility layer, or the multiplicative inverse/division they require. Those arrive together in a later pass.

N.b. like Affine, an empty Taylor (default-constructed, or explicitly constructed from an empty interval) represents the empty set, not the constant 0. This is a different notion of "empty" than Monomial's, which denotes its multiplicative identity.

◆ bound()

template<typename ValueType>
auto sigma::Taylor< ValueType >::bound ( ) const

Returns an interval enclosing the values of the polynomial.

Computes \(B(P)\) of Eq. \(\eqref{eq:tm-bound}\) using Berz and Makino's quadratic fast bounder (QFB), per docs/taylor.md's "Dominated and fast bounders" section. For each expansion variable \(\delta_i\), its diagonal contribution \(c_{e_i}\delta_i + c_{2e_i}\delta_i^2\) (the linear and pure-quadratic terms in \(\delta_i\) alone) is bounded exactly, in closed form, by completing the square – no dependency-problem overestimation, since each \(\delta_i\) is independent of every other. Everything else (cross terms and degree- \(\geq 3\) terms) is bounded by the naive per-term baseline instead. The two are summed with the constant term to produce the final enclosure.

Returns
An interval enclosing the values of *this over its domain.
Exceptions
std::domain_errorIf *this is empty. Strong throw guarantee.

◆ compose_()

template<typename ValueType>
auto sigma::Taylor< ValueType >::compose_ ( const std::vector< value_t > & outer_coeffs) const

Evaluates a truncated outer Taylor series about the constant term of *this.

This is the hook every elementary function (sqrt, exp, log, pow, multiplicative_inverse, ...) is built from – the direct generalization of Affine::apply_affine_transform to arbitrary order. Given the Taylor coefficients of an outer function \(g\) about \(c_f\) = constant(), i.e. outer_coeffs[k] = \(\frac{1}{k!}\frac{d^k g}{df^k}(c_f)\), this computes

\[ \sum_{k=0}^{n} \texttt{outer\_coeffs}[k]\, \bar{P}^{\,k} \]

where \(\bar{P}\) = *this - constant() and \(n\) = max_order(), using ordinary Taylor polynomial addition and multiplication (which truncate at \(n\)). Because \(\bar{P}\) has no constant term, \(\bar{P}^{k}\) has no terms below degree \(k\), so entries of outer_coeffs beyond index \(n\) would only ever multiply terms that are truncated away; callers need not (but may) supply them.

Parameters
[in]outer_coeffsThe Taylor coefficients of the outer function about constant(), starting from k=0.
Returns
The truncated composition of the outer function with *this.
Exceptions
std::domain_errorIf *this is empty. Strong throw guarantee.
std::bad_allocIf memory allocation for the new polynomial fails. Strong throw guarantee.

◆ derivative()

template<typename ValueType>
auto sigma::Taylor< ValueType >::derivative ( deviation_t var) const

Returns the partial derivative of *this with respect to var.

Ordinary term-by-term polynomial differentiation: a term \(c\,\delta^{\beta}\) with \(\beta_{\texttt{var}} = e > 0\) differentiates to \(ce\,\delta^{\beta - e_{\texttt{var}}}\), where \(e_{\texttt{var}}\) is the multi-index with a 1 in the var slot and 0 elsewhere; terms not involving var vanish. Differentiation cannot raise degree, so it never has terms to drop. The truncation order of the result is the same as *this.

Parameters
[in]varThe expansion variable to differentiate with respect to.
Returns
The partial derivative of *this with respect to var.
Exceptions
std::domain_errorIf *this is empty. Strong throw guarantee.

template<typename ValueType>
auto sigma::Taylor< ValueType >::operator*= ( const Taylor< ValueType > & other)

Overwrites *this with the product of *this and other.

Implements the polynomial part of Eq. \(\eqref{eq:tm-mul}\), \((P_1 P_2)_{\leq n}\): the exact product, truncated to the smaller of *this's and other's truncation orders. Unlike TaylorModel (not yet implemented), Taylor has no remainder to bound the discarded terms into, so they are simply dropped – consistent with Taylor making no claim to enclose anything. As with operator+=(Taylor), mixed orders resolve to the smaller of the two.
