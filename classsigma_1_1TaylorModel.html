Detailed Description

template<typename ValueType>
class sigma::TaylorModel< ValueType >

Pairs a Taylor polynomial with a remainder interval to guarantee Eq. \(\eqref{eq:tm-inclusion}\).

Template Parameters
ValueTypeThe numeric type of the constant term, coefficients, and remainder bounds.

Where Taylor alone makes no claim to enclose anything, TaylorModel does: for every \(\delta \in [-1,1]^v\), range() – \(B(P) + I\) – encloses the modeled function. Every operation below exists to preserve that property (docs/taylor.md's "Every operation defined below exists to preserve Eq. \_form#83"): where Taylor's own arithmetic would silently discard a term it cannot represent, TaylorModel instead bounds that term with Taylor::bound() and folds it into the remainder.

Structurally this follows ThresholdedAffine: composition rather than inheritance, forwarding accessors, a polynomial() accessor exposing the underlying Taylor, and mutating operators that delegate and then repair the remainder. Unlike ThresholdedAffine, nothing here is auto-applied after every operation – sweep_to_order() and sweep_small() are explicit, user-invoked tools for controlling term count, matching the discipline Eq. \(\eqref{eq:tm-inclusion}\) demands: dropping a term without bounding it would invalidate the model, not merely loosen it.

Elementary functions (sqrt, exp, log, pow) and division are implemented as free functions and a multiplicative_inverse member, respectively, using the private compose_ hook: it evaluates the polynomial part exactly as Taylor::compose_ does, then bounds the discarded tail of the outer series with the Lagrange remainder of Eq. \(\eqref{eq:tm-outer-rem}\) and folds it into the returned model's remainder, so Eq. \(\eqref{eq:tm-inclusion}\) survives the operation (see docs/taylor.md's "Elementary functions" section). Antiderivation is still deferred; see docs/taylor.md's note on Eq. \(\eqref{eq:tm-antideriv}\) – nothing on this page depends on it.

Constructs a TaylorModel from an interval.

For a non-empty interval, the underlying polynomial is Taylor(interval, order). If order is at least 1, that polynomial represents interval exactly (a single linear term on a freshly minted expansion variable), so the remainder is empty – matching the Affine: order 1, empty remainder row of docs/taylor.md's equivalence table. If order is 0, Taylor has nowhere to put the linear term, so it is dropped from the polynomial and its full contribution becomes the remainder instead, preserving Eq. \(\eqref{eq:tm-inclusion}\). If interval is empty, the resulting model is also empty.

Parameters
[in]intervalThe interval represented by the model.
[in]orderThe truncation order, defaults to default_max_order().
Exceptions

Evaluates a Taylor-model outer series about constant(), with a Lagrange remainder bound.

This is the TaylorModel analogue of Taylor::compose_ – the hook every elementary function is built from. It computes the polynomial part exactly as polynomial().compose_(outer_coeffs) does (see Taylor::compose_), then bounds the discarded tail of the outer series with the Lagrange remainder of Eq. \(\eqref{eq:tm-outer-rem}\)

\[R_{n} \in \frac{1}{\left(n+1\right)!} \left(B\left(\bar{P}\right) + I\right)^{n+1} \frac{d^{n+1}g}{df^{n+1}}\Big( c_f + \left[0, 1\right] \cdot \left(B\left(\bar{P}\right) + I\right) \Big) \]

Parameters
[in]outer_coeffsThe Taylor coefficients of the outer function \(g\) about constant(), starting from k=0; forwarded verbatim to polynomial().compose_.
[in]nth_derivativeA callable computing \(\frac{d^{n+1}g} {df^{n+1}}\), evaluated in interval arithmetic over the argument range in Eq. \(\eqref{eq:tm-outer-rem}\) above, where \(n\) = max_order().
Returns
A TaylorModel of \(g(f)\), where \(f\) is the function modeled by *this.
Exceptions

◆ operator*=() [1/2]

template<typename ValueType>
auto sigma::TaylorModel< ValueType >::operator*= ( const TaylorModel< ValueType > & other)

Overwrites *this with the product of *this and other.

Implements Eq. \(\eqref{eq:tm-mul}\). As in operator+=(TaylorModel), mixed orders are first resolved by sweeping the higher-order operand down with sweep_to_order(), so the base formula only ever has to handle two equal-order polynomials:

\[\left(P_1, I_1\right) \cdot \left(P_2, I_2\right) = \left( \left(P_1 P_2\right)_{\leq n},\; B\left(\left(P_1 P_2\right)_{>n}\right) + B\left(P_1\right) I_2 + B\left(P_2\right) I_1 + I_1 I_2 \right) \]

Unlike Taylor::operator*=(Taylor), which simply discards \((P_1 P_2)_{>n}\), this bounds it with Taylor::bound() and folds it into the remainder, so Eq. \(\eqref{eq:tm-inclusion}\) survives the operation.

Parameters
[in]otherThe model to multiply *this by.
Returns
Reference to this model after multiplication.
Exceptions
std::bad_allocIf memory allocation for the new model fails. Strong throw guarantee.

◆ sweep_small()

template<typename ValueType>
auto sigma::TaylorModel< ValueType >::sweep_small ( value_t threshold) const

Removes individually small coefficients, bounding them into the remainder.

Serves the purpose that ThresholdedAffine's automatic thresholding serves – controlling how many terms are carried – but rigorously: a coefficient \(c_\beta\) is removed when \(|c_\beta| / \mathrm{radius}(\mathrm{range}()) < \) threshold (every monomial is bounded in magnitude by 1 over \([-1,1]^v\), so \(|c_\beta|\) is exactly that term's maximum contribution), and its contribution is bounded with Taylor::bound() and added to the remainder rather than discarded.

Parameters

Returns
*this, with small coefficients swept into the remainder.
Exceptions
std::domain_errorIf *this is empty. Strong throw guarantee.

◆ sweep_to_order()

template<typename ValueType>
auto sigma::TaylorModel< ValueType >::sweep_to_order ( size_type new_order) const

Reduces *this to a lower truncation order, bounding the removed terms into the remainder.

Every coefficient whose monomial has degree above new_order is removed from the polynomial; their combined contribution is bounded with Taylor::bound() and added to the remainder. Unlike Taylor::truncate(), which simply discards those terms, this preserves Eq. \(\eqref{eq:tm-inclusion}\) – the enclosure gets wider, never invalid. If new_order is greater than or equal to max_order(), nothing is removed and the remainder is unchanged.

Parameters
[in]new_orderThe truncation order of the result.
Returns
*this, reduced to new_order.
Exceptions
std::domain_errorIf *this is empty. Strong throw guarantee.

Unlike the elementary functions below, \(|\cdot|\) has no Taylor series at points where its argument's range straddles 0, so it is not built from compose_(). Power of a TaylorModel.

Template Parameters
TThe value type of the model.
UThe type of the exponent.

For a strictly one-signed range this method takes advantage of the fact that:

\[x^y = e^{y \log(x)} \]

mirroring Affine::pow. If range() straddles or touches 0 (and is not exactly the point 0, where \(0^y = 0\) for any \(y > 0\)), neither \(\log\) branch is valid, so exp must be a positive integer, and the result is computed by repeated multiplication instead – which stays rigorous (Eq. \(\eqref{eq:tm-mul}\)) across a zero-containing range, unlike the \(\log\)/ \(\exp\) route.
