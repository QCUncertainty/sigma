Detailed Description

Shared helpers for building the outer Taylor series of the elementary functions (exp, log, 1/x, sqrt).

These are used both by Taylor's own (non-rigorous) elementary functions in operations/exponents.ipp and by TaylorModel's, which additionally need the (n+1)-th derivative of the same outer function for the Lagrange remainder of Eq. \(\eqref{eq:tm-outer-rem}\) (see docs/taylor.md).

is_integer_exponent(), used by pow() but not itself series-related, lives in sigma/detail/numeric.hpp and is re-exposed here (via the include above) so existing callers of detail::is_integer_exponent under sigma/taylor/ keep working unqualified.
