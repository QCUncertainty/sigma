Detailed Description

template<typename ValueType>
struct sigma::Taylor< ValueType >::Order

Tag type used to pass the truncation order to constructors.

Wrapping the order in this type avoids overload ambiguity between Taylor(value_t center, Order order) and Taylor(value_t lo, value_t hi).

Example:

Taylor<double> x(1.0, Taylor<double>::Order{4});
